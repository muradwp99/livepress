# Translations

This directory holds the plugin's `.pot` template and any `.po`/`.mo`/`.json`
translations. It is otherwise empty on purpose.

## Regenerating the template

```bash
wp i18n make-pot . languages/livepress.pot
wp i18n make-json languages --no-purge     # the editor's strings, for wp.i18n
```

`livepress.pot` is committed and current. Regenerate it whenever strings
change — the header carries the plugin version, so a stale template is
visible rather than silent.

It was generated by the real extractor, not by hand, and that decision paid
for itself immediately: the first run reported five strings carrying
placeholders with no `translators:` comment, and finding those led to a sixth
string that had never been wrapped at all. A hand-rolled generator would have
emitted a template that looked complete and quietly omitted them.

It also picked up the plural inside `assets/editor.js`. A PHP-only extractor
would have left the editor — where most of the words are — out of the
template entirely.

## Text domain

`livepress`, declared in the plugin header and loaded on `init`. Every call
passes it explicitly rather than through a wrapper, because the extractor
reads source text and cannot follow one.
